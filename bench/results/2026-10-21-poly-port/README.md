# Original Strata + optional Poly engines: integration check

Date: 2026-10-21. Base: Niko1221/Strata `011c9e60`. Poly sources: ersensari/PolyStrata `f6c93f63`.
This is a compatibility check, **not a throughput or model-quality benchmark**.

Host: Ryzen 9 9900X, 96 GB RAM, RTX 5060 Ti 16 GB, CUDA 13, `sm_120`. The development container exposed
**only host GPU 1** using CDI. Host GPU 0 workloads were not modified. Production PolyStrata was stopped
before any GPU unit test or model inference. Models were loaded sequentially and each server/engine exited
before the next. Production remains stopped at the owner's request after the checks.

## Real models and new source server

Each model used `python -m serve.server --engine strata --port 8080 --config <private-run-config>` from
this checkout. Requests used `temperature: 0`, `reasoning_effort: "none"`, `max_tokens: 512`.
All reported configured context capacity 262144, but requests were short. The model files already existed;
no model was downloaded for this check. Configs and keys are not included in this record.

| Model / engine | Request and verification | Result |
| --- | --- | --- |
| AtomicChat Ornith AD-IQ3_XXS / new `strata-poly` | Define `add(a,b)` in Python; parse AST, refuse imports, execute and assert four integer/float pairs | Pass, normal stop |
| MiniCPM-V 4.7 Q4_K_M / new `strata-poly` | A generated solid-red 384×384 PNG; name dominant color in one English word | `Red`, normal stop |
| Gemma 4 UD-Q4_K_M / new `strata-poly` | Request declared `weather` tool for Ankara; validate name and JSON city argument | Pass, `tool_calls` |
| Swift/Qwen IQ3_XXS / new **original native** `strata` | Same Python `add(a,b)` validation | Pass, normal stop |

Ornith additionally exercised the new local importer: its run config and tokenizer were generated by
`tools/poly_import.py`, with Q8 KV, CPU vision, 12 threads, 1024 MiB reserve, Poly fast attention and CPU IQ
multi-token opt-ins. The other run configs reused local packs, with private copied expert profiles and logs;
production data/engine volumes and model mounts were read-only inside the test container.

The MiniCPM request used the already installed Poly vision binary built against `69f201a`. The newly compiled
encoder was not substituted for that request; its result above is a separate compilation check.

[Raw responses and timings](model-smoke.json) include only 13 generated tokens for each coding question,
2 for the image question and 14 for the tool call. These are too short to compare sustained decode rates.
In fact, the same 13-token Ornith request measured 28.3 tok/s in an earlier cold run and 44.8 tok/s in the
recorded run, illustrating why these figures must not be read as a speed improvement. No claim of a speedup
over the existing PolyStrata deployment follows from this record.

## Scope of the result

The imported engines communicate with the original Strata server, while the original Qwen engine and app
source remain intact. GLM/DeepSeek/LFM tool formats have unit coverage, but their actual model files were
not exercised. Long-context stability, long coding tasks, full multimodal coverage, sustained throughput,
desktop model installation and production migration remain outside this integration check.
